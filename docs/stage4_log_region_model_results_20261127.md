# Stage 4 对数区域载荷：MLP–Reptile 探索性模型复核（2026-11-27）

**状态：探索性、目标与长训练设置均为事后选择。** 本文件接续[物体信号审计](stage4_object_signal_audit_results_20261127.md)，以保留空间与力值的对数区域载荷变化为目标。[固定配置与优化敏感性协议](stage4_log_region_model_pilot_protocol.md)及[机器可读结果](../results/stage4_log_region_model_summary_20261127.json)包含参数、三个种子、逐物体配对区间和折 0 诊断。

## 任务与比较

使用冻结的 EgoTactile-OXT Stage 1 压力数据，63 个物体、692 条参与者–物体记录。按物体五折留出，测试物体完全不进入训练；Query 参与者可在其他训练物体出现，同物体 Support 不含 Query。输入为两个完整的 0.5 秒 bin 的六区域 `log1p` 平均载荷；预测四个未来 bin 相对最后一个输入 bin 的变化，输出 4 × 6。指标是这 24 个对数载荷变化值的 MAE，逐物体等权。

比较持久性、训练物体全局变化、Query 的跨物体历史、跨物体历史加固定 25% 的同物体 Support 校正、普通 MLP（未适应及微调）、Reptile（未适应及适应）。MLP 与 Reptile 网络均为 12→32→32→24，训练物体折、测试 Query 与 Support 组合相同；三个训练种子为 20261127–29。每个种子的物体 bootstrap 区间都基于 63 个物体、5000 次重采样。

## 预先固定的低预算配置

普通 MLP：1500 步 Adam、批量 3；Reptile：500 个物体任务，每任务 3 步 SGD；测试时两者均用 3 步、学习率 0.05。样本接触量约 4500 对 4000，计算与优化器并不完全相等。

| 三种子平均 MAE | 1-shot | 2-shot | 5-shot |
| --- | ---: | ---: | ---: |
| 同参与者历史 + 25% Support | 0.7481 | 0.7331 | 0.7255 |
| MLP 未适应 | 0.6611 | 0.6611 | 0.6611 |
| MLP 微调 | 0.6866 | 0.6721 | 0.6493 |
| Reptile 未适应 | 0.8971 | 0.8971 | 0.8971 |
| Reptile 适应 | 0.9214 | 0.9105 | 0.9016 |

低预算 Reptile 连训练物体全局变化基线（约 0.8459）也未超过，说明它可能明显欠训练。MLP 在 1/2-shot 微调后变差，5-shot 略有收益；不能仅以“微调有时退化”推断 Reptile 有优势。

## 事后优化敏感性

看到低预算结果后，在已经被查看的折 0 上增加 Reptile 外循环到 1500、3000、6000 次。其未适应 MAE 分别约为 0.770、0.715、0.679，表明训练不足是原差距的重要来源。折 0 的 6000 次模型在测试适应学习率 0、0.005、0.01、0.02、0.05、0.1 中，以 0.005 取得最低 5-shot MAE（约 0.676）。**这些数字用于诊断，不能把折 0 再当独立验证集。**

随后用 6000 次外循环、元训练内循环学习率 0.05、Reptile 测试适应学习率 0.005，完整重跑五折与三个种子；MLP 保持原来的 1500 步训练和 0.05 适应学习率。Reptile 此时约接触 48,000 条训练记录（含任务内重复），MLP 约 4,500 条；这是**额外训练预算的敏感性分析**，不是等预算胜负试验。

| 三种子平均 MAE | 1-shot | 2-shot | 5-shot |
| --- | ---: | ---: | ---: |
| MLP 未适应 | 0.6611 | 0.6611 | 0.6611 |
| MLP 微调 | 0.6866 | 0.6721 | 0.6493 |
| 长训练 Reptile 未适应 | 0.6914 | 0.6914 | 0.6914 |
| 长训练 Reptile 适应 | 0.6881 | 0.6867 | 0.6845 |

长训练 Reptile 的 5-shot 适应相对自身未适应，三个种子分别改善 0.00685、0.00711、0.00669；各自 95% 逐物体区间均大于 0，改善物体为 45、46、45/63。**这说明该配置可以少样本适应，并修正了低预算配置下“适应变差”的表象。** 但 MLP 微调相对长训练 Reptile 适应的 5-shot MAE 分别低 0.03485、0.03808、0.03288，三个种子的配对区间都不跨零；MLP 未适应的平均 MAE 也更低。1-shot 下，长训练 Reptile 仅比自身未适应好约 0.0033，仍劣于无需 Support 的 MLP。

三个种子使用相同物体折与 Support 组合，不能视为三个独立数据集。所有区间条件于对应训练种子，且优化设置使用折 0 和已查看的 63 个物体挑选；**这些区间不能消除事后选择偏差**。

## 研究判断

1. 当前数据并非没有物体信号：Stage 4 的参与者内置换审计显示物体相关成分高于随机对应；5-shot 简单强收缩也有微小收益。
2. Reptile 的低预算失败有明显优化因素。增加任务数、降低测试适应步长后，它出现稳定但较小的 Support 增益。
3. 对核心命题“Reptile 在未见物体的少样本结构预测上优于普通 MLP”，**本阶段仍没有支持证据**。更强的无适应 MLP 已低于长训练 Reptile 的适应误差。
4. 当前 0.5 秒、六区域聚合是离线人类触觉信号；它不验证原始 137 传感器的动态空间结构，也不证明机器人在线适应。下一轮若要形成可信研究结论，应先获得未参与目标和参数选择的独立物体测试集，并在训练物体内部选择双方的训练预算与适应学习率。若能取得原始高时间分辨率压力，再定义有物理意义的接触变化目标。
