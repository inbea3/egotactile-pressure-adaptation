# Stage 3 动态压力少样本适应：AutoDL 阶段性结果（2026-11-27）

## 研究问题与执行状态

在未见物体上，给定同一物体的 1、2、5 条其他参与者触觉记录，Reptile 初始化及其少样本适应能否比普通 MLP 及其微调更准确地预测后续压力空间分布？

本阶段已在 AutoDL 容器完成 63 个物体的五折全覆盖试验。Stage 3 的无模型门槛未通过，因此下面的神经网络试验是**探索性附加试验**，不能作为元学习有效或无效的一般性证明。实验代码、预定协议和数值摘要已保存于本分支；完整逐物体结果保留在容器。

## 数据与任务

- 数据：冻结的 EgoTactile-OXT Stage 1 全事件清单，修订号 `5b05f19e613758e76c330671f4c9f3c06af8af44`，清单 SHA-256 `76cd77723d01904296deabfe7755ff489f609bc3c7284c6ea6c91c40f6afb65c`。
- 合格样本：63 个物体、692 条参与者–物体记录。**一条完整记录算一个 shot**，不把时间窗口或压力周期拆成独立样本。
- 使用因果起始规则 `two_sensors_gt_5N_3samples`。输入为前两个完整的 0.5 秒压力区域份额；预测后四个完整的 0.5 秒份额。每帧为六个区域加一个无接触通道；本批合格记录的无接触通道恒为 0。
- 神经网络预测后四帧相对最后一帧输入的残差，最终预测投影到份额单纯形。指标为四帧七通道的平均绝对误差（MAE），先对 Support 组合、Query 参与者求平均，再对物体等权平均。
- 五折按物体划分：测试物体的全部记录不进入训练；其 Query 参与者可出现在训练物体上；测试物体的 Support 参与者与 Query 不同。两个模型用相同的五折和 Support 组合。结果对应**未见物体、已见参与者**，不能外推为新参与者适应。

## Stage 3 无模型门槛

在更严格的 Query 参与者阻断全局模板下，5-shot 固定 25% Support 收缩把 MAE 从 0.059591 降到 0.058743，逐物体配对增益 0.000848，95% 物体 bootstrap 区间 [0.000514, 0.001240]；1-shot 无稳定收益。但不收缩的物体残差模板比全局模板差 0.000613，区间 [-0.001392, 0.000286]，只有 18/63 个物体改善。跨物体的同参与者历史模板约 0.0521，强于这些模板。另一种起始规则方向相同。[无模型数值摘要](../results/stage3_dynamic_support_summary_20261127.json)给出完整结果。

这说明少量 Support 在强收缩下带来微小校正，却未显示稳定的、可直接学习的物体特有残差。按[预定 Stage 3 协议](stage3_dynamic_target_protocol.md)，不满足启动确认性 Reptile 研究的门槛。

## MLP–Reptile 探索性试验

[模型试验协议](stage3_model_pilot_protocol.md)冻结了双隐藏层、宽度 32 的残差 MLP、相同初始化结构、3 步 Support SGD（学习率 0.05）、1/2/5-shot 评估、每 Query 最多五组 Support、5000 次物体 bootstrap。普通 MLP 用 Adam 训练 1500 步；Reptile 用 500 个物体任务、每任务 3 步内循环。没有用测试物体挑超参数。

首轮 MLP 批量 32，与 Reptile 的训练样本接触量不匹配。发现后追加了**事后公平性敏感性分析**：MLP 批量改为 3，约 4500 个样本接触；Reptile 约 4000 个样本接触。固定五折与 Support 组合，重复三个训练种子。批量 32 的原结果仍保留。接触量接近不等于优化器、计算量或调参预算完全等同。

| 批量 3，三个种子均值 MAE | 1-shot | 2-shot | 5-shot |
| --- | ---: | ---: | ---: |
| MLP，未适应 | 0.04433 | 0.04433 | 0.04433 |
| MLP，Support 微调 | 0.04816 | 0.04594 | 0.04336 |
| Reptile，未适应 | 0.05762 | 0.05762 | 0.05762 |
| Reptile，Support 适应 | 0.06018 | 0.05930 | 0.05846 |

同一五折的持久性、训练物体全局转移和同参与者历史转移基线分别为 0.06997、0.05838、0.05216 MAE。首轮批量 32、种子 20261127 的 5-shot MLP 微调为 0.04231，Reptile 适应为 0.05856；接触量匹配后对应为 0.04316 和 0.05856。Reptile 的训练过程未随 MLP 批量变化，所以这个种子的 Reptile 数值相同。

以“MLP 微调 MAE − Reptile 适应 MAE”为正向比较，批量 3 的三个种子在 5-shot 分别为 -0.01541、-0.01483、-0.01507；各自的 95% 逐物体 bootstrap 区间分别为 [-0.01668, -0.01408]、[-0.01615, -0.01357]、[-0.01633, -0.01378]，三个种子均为 **0/63** 个物体有利于 Reptile。1-shot 与 2-shot 也有相同方向。以上区间分别**条件于一个训练种子**，并非合并种子后的置信区间。

MLP 微调在 1-shot 和 2-shot 均劣于其未适应模型；5-shot 的微小改善在三个种子中分别为 0.00065、0.00119、0.00105，其中只有一个种子的物体 bootstrap 区间完全大于 0。Reptile 的 Support 适应在三个 shot 水平均劣于其未适应初始化。完整均值、配对差、区间和参数见[机器可读数值摘要](../results/stage3_model_pilot_summary_20261127.json)。

## 判断与限制

当前结果**不支持**“这套动态区域份额预测任务上 Reptile 比普通 MLP 更能少样本适应未见物体”的命题。样本接触量复核和训练种子复核没有改变这一点。它也不证明 Reptile 对所有触觉任务无用：本试验只覆盖一个较小的网络、一套 Reptile 步数与学习率、一个因果起始规则、一个聚合后的目标，以及已见参与者场景。

更关键的研究风险是任务定义。区域份额的 0.5 秒聚合丢失了原始压力细节和绝对力；第七通道实际恒零；同参与者历史很强，而无模型物体残差模板不占优。因此模型可能主要学习常见时序转移和参与者习惯，而非可迁移的物体交互结构。所有记录来自离线人类触觉数据，也未检验真实机器人控制或在线适应。

## 建议的下一步

1. **先检验目标是否含有物体特有信息。** 在训练物体内部做参与者与物体的方差分解，并用相同早期输入比较“同物体其他参与者”和“不同物体同参与者”的未来轨迹相似度。这是继续投入元学习前的任务检验。
2. 若物体信号仍弱，保留当前泄漏审计、因果起始、物体折、Support/Query 组织和 MLP 对照框架，改用更细的原始压力时空序列与物理上可解释的目标（如接触区域转移、压力中心轨迹、滑移或接触状态变化）；先做无模型门槛与强基线。
3. 只有在新目标显示稳定物体效应后，才在**训练物体内部**设置验证物体选择 Reptile 内外步数、学习率和适应步数；锁定参数后用完全未触及的测试物体评价，并追加新参与者外推。当前五折已经被查看，不能再当作未触及确认集。
